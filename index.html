I’m Josh Kroslowitz, a software engineer passionate about building immersive products and visual experiences.

My work has taken me from developing interactive 3D applications in Unity and C# to building web applications, backend services, and cloud infrastructure using TypeScript, React, Next.js, Python, and PostgreSQL. More recently, I've been working on Gaussian splatting, browser-based 3D rendering, and GPU processing pipelines, helping build a platform that turns real-world captures into interactive 3D environments.

I started out studying animation but discovered I enjoyed building the tools behind creative experiences more than creating the art itself. I've been writing software ever since. I've worked on everything from small development tools to enterprise applications and production systems. What I enjoy most is solving difficult technical problems, improving performance, and building software that's not just functional, but genuinely enjoyable to use.

Musubi Motion

A browser-based, splat-native 3D animation editor bringing traditional character animation tools to Gaussian splatting.

  • Three.js / Spark / WebGL2
  • Traditional animation tool for Gaussian splats
  • Dynamic splat generation and deformations
Project notes +

Musubi Motion is entirely browser-based and built with Three.js, Spark and WebGL2. It incorporates elements of several existing libraries such as UI elements, but is built from the ground up to be a fully featured animation studio for Gaussian splats. Many parts including splat deformation and FBX to splat conversion are custom built.

GaussMark

GaussMark is a browser-based 3D rendering benchmarking tool that allows you to compare the performance of different 3D rendering techniques.

  • Graphics pipeline
  • Data processing
  • Performance considerations
Project notes +

GaussMark allows developers to benchmark the performance of different 3D rendering techniques in the browser. With specific focus on Gaussian splatting, it allows developers to compare the optimization and efficiency of different Gaussian splatting techniques. GaussMark is built with TypeScript and Rust and currently allows for users to test with PlayCanvas, WebSplatter, Three.js and Spark or their own custom implementations.
